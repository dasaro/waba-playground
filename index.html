📚 WABA Playground Documentation

Welcome to WABA Playground! 👋

WABA (Weighted Assumption-Based Argumentation) extends flat ABA with weights on the leaves of a derivation. An ordered semiring propagates them, and a set of assumptions is accepted only if the objections it concedes fit an inconsistency budget β.

🎯 Quick Start Workflow

  1. Configure: Pick an algebra (how weights propagate) and a semantics; the budget reading is preselected to match the algebra
  2. Define Framework: Load an example or write your own in Simple/Advanced mode
  3. Run: Click "▶️ Run WABA" to compute extensions
  4. Explore: View results and interact with the argumentation graph

💡 Key Concepts

Assumptions
Defeasible statements that can be in or out of extensions
Weights
Positive integer costs/rewards assigned to arguments
Attacks
Relations where one argument challenges another
Extensions
Consistent sets of assumptions that defend themselves from attacks
Budget
Maximum cost allowed for discarding attacks (optional)

📂 File Formats

Upload your frameworks in two formats:

  • .waba - Simple, human-readable format (recommended for beginners)
  • .lp - Advanced ASP format with full expressiveness

Framework Syntax

📄 Simple Mode (.waba Format)

Simple Mode uses a structured text format with four sections. Comments use %.

1. Assumptions 
a
b
c

One assumption per line. These are defeasible atoms that can be in or out of extensions.

2. Rules 
conclusion ← premise1, premise2
attack ← a

One rule per line using ← (or <-) to separate head from body.

3. Contraries (Attacks) 
a: attack_element
b: conclusion

Format: attacked: attacker
⚠️ Direction: attacker attacks attacked (not the reverse)

4. Weights 
a: 80
b: 60
attack_element: 70

Format: atom: weight. Assigns positive integer weights. An atom you leave out is not weighted 1 — an unweighted assumption takes δ, the default set by the Unweighted assumptions (δ) control: neutral gives it the algebra's ⊗-identity (no effect on a derivation), aba gives it #sup (un-droppable, recovering plain ABA).

Complete .waba Example 
% Medical triage example
a
b

attack_element ← a

b: attack_element

a: 80
b: 60
attack_element: 70

⚡ Advanced Mode (.lp Format)

Advanced Mode uses Answer Set Programming (ASP) syntax with WABA predicates.

Predicates Reference
Predicate Syntax Description
assumption assumption(a). Declares a defeasible assumption
weight weight(a, 80). Assigns weight to an atom
head/body head(r1, c). body(r1, a). Defines inference rules
contrary contrary(a, c). c attacks a
budget budget(100). Ignored. β comes only from the Inconsistency budget control, passed as -c beta, which overrides any #const or budget/1 in the framework.
Complete .lp Example 
% Assumptions
assumption(a).
assumption(b).

% Weights
weight(a, 80).
weight(b, 60).
weight(attack_element, 70).

% Rules
head(r1, attack_element).
body(r1, a).

% Contraries
contrary(b, attack_element).

No budget/1 fact: β is set by the Inconsistency budget control, not by the framework.

Configuration Options

🔢 Semiring (Weight Propagation)

Controls how weights propagate through inference rules.

Semiring Conjunction (⊗) Disjunction (⊕) Use Case
Gödel min max Higher-is-better fuzzy reasoning
Bottleneck-cost (Gödel lower) max min Lower-is-better worst-case cost
Arctic (Tropical higher) + max Higher-is-better accumulated reward
Tropical (Tropical lower) + min Lower-is-better additive cost / shortest path

Five algebras. Four form a 2×2 over ⊗ (idempotent / additive) and polarity (⊕ = max is strength, ⊕ = min is cost): godel, bottleneck_cost, arctic, tropical. lukasiewicz sits outside it (bounded sum). godel_low and tropical_high are polarity-dual aliases of bottleneck_cost and arctic.

📊 Budget reading (β)

How the objections an extension concedes are priced against the budget. Monoid and bound are no longer separate controls: only the three canonical pairings are offered, so an incoherent one is unreachable rather than merely discouraged.

Reading Aggregate Weights mean Accepts when
Sum ≤ β Σ of conceded weights strength — bigger is harder to overrule the total conceded is at most β
Max ≤ β max of conceded weights strength no single concession exceeds β
Min ≥ β min of conceded weights weakness — bigger is easier to concede every concession is worth at least β
No discarding — — nothing may be conceded, i.e. plain ABA

Choosing an algebra preselects the reading that matches its polarity: strength algebras get Sum ≤ β, cost algebras get Min ≥ β. The boundary is non-strict, so an extension costing exactly β survives. Note that Sum ≤ β with β = 0 is not the same as no discarding: an attack whose propagated weight is 0 is still discardable. Use ABA recovery for exact recovery.

🎯 Semantics

Which sets of assumptions count as acceptable. All five consume the weights; none is weight-blind.

Semantics Description How β applies
Conflict-free No supported attack between selected assumptions via the budget reading
Stable Conflict-free, and every assumption left out is attacked via the budget reading
Admissible Conflict-free and defends every member internal: one shared pay set covers internal conflict and undefended attack
Complete Admissible, and contains everything it defends internal, as admissible
Preferred The subset-maximal admissible sets internal, as admissible

The last three are a structured lift of the Dunne et al. (AIJ 2011) inconsistency budget, so they take β directly and the budget-reading control does not apply to them. Their bound direction follows the algebra's polarity: under a strength algebra the conceded weights must sum to at most β, so plain ABA is recovered at β = 0; under a cost algebra the smallest concession must be at least β, so recovery arrives at a β above every attack weight.

🎚️ Results

All extensions
Enumerate every extension the budget admits. This is the only option for Preferred, which is computed by subset-maximal filtering over enumerated candidates and therefore needs them all.
Cheapest only / Dearest only
Keep just the optimum of the aggregate named by the budget reading. Available only when a budget reading is active — with nothing conceded there is nothing to optimise.

Understanding Results

📋 The extension card

Each answer set is one extension. Cards are sorted best-first: under a strength algebra the cheapest concession comes first, under a cost algebra the best-supported does.

Extension n
Click the header to colour that extension into the graph; click it again to clear.
The badge
Names its own aggregate rather than saying “Cost”, because what the number measures depends on the run: Σ conceded, worst conceded or least conceded for the sum, max and min monoids. Under a defence semantics no monoid runs, so the badge instead reports the probed β*: β* needed (the least budget that admits the set) under a strength algebra, β* up to (the largest budget it survives) under a cost one.
Assumptions
A green ✓chip per accepted assumption, a grey ✗chip per rejected one.
Active Attacks
Written a1, a2 ⊢ c [t]: the assumptions on the left derive the attacking element c, which defeats t. A ⊤ on the left means the element needs no assumption at all.
Discarded Attacks
Same shape with ⊼, plus the weight that was paid for declining it. These are what the budget buys.
Derived Atoms
Non-assumption conclusions that hold, each with its propagated weight. Click one to see the rule that derives it.
Active Contraries
Every contrary that is supported, and whether its target survived.
Textual Result
Collapsed by default: the raw in/1, supported_with_weight/2, discarded_attack/3, budget_value/1 and cost/1 atoms, as clingo reported them.

📈 Execution stats

One line under the cards: how many extensions were found, how long the solve took, which algebra ran, and the reading the budget was given — for instance sum of concessions ≤ β, or unanswered objections ≤ β under a defence semantics. When nothing may be conceded and the semantics has no budget of its own, the algebra is flagged unused, because no weight is priced on such a run.
