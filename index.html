WABA propagates support weights through an ordered semiring, gives unweighted assumptions a default weight, and accepts a set only if the objections it concedes fit an inconsistency budget β.

Reference

Simple format .waba

% a comment

assumptions
a
b

rules
c ← a, b

contraries
b: c

weights
a: 80
b: 60
Assumptions
One per line. Defeasible: each is in or out of an extension.
Rules
head ← body. The body may be empty (a fact).
Contraries
attacked: attacker. The attacker is on the right. Every assumption needs exactly one.
Weights
atom: n, a positive integer. An atom you omit takes δ, set by the Unweighted assumptions control — never 1.

Advanced format .lp

% the same framework in ASP

assumption(a).  assumption(b).
weight(a, 80).  weight(b, 60).

head(r1, c).  body(r1, a).  body(r1, b).

contrary(b, c).
assumption/1
Declares a defeasible atom.
weight/2
At most one per atom; a duplicate is rejected.
head/2, body/2
A rule, keyed by its own identifier.
contrary/2
contrary(a, c) means c attacks a.
budget/1
Ignored. β comes only from the budget control, passed as -c beta.

The framework must be flat: an assumption may never be a rule head. Rules may not be circular.

Algebras

How a weight propagates along a derivation. ⊗ combines the premises of one rule; ⊕ combines rival derivations of the same atom.

Algebra⊗⊕Reads a weight as
Gödelminmaxstrength — only as strong as its weakest premise
Arctic+maxstrength — independent premises accumulate
Łukasiewiczmax(0, a+b−k)maxstrength — a long chain erodes toward 0
Tropical+mincost — cheaply derived means well supported
Bottleneck-costmaxmincost — costs as much as its dearest premise

Polarity is a property of the algebra, not a separate control. godel_low and tropical_high are aliases for Bottleneck-cost and Arctic in saved configurations.

Budget (β)

What the objections an extension concedes cost against the budget. Only the three coherent pairings are offered.

ReadingAccepts whenSuits
Sum ≤ βthe total conceded is at most βstrength algebras
Max ≤ βno single concession exceeds βstrength algebras
Min ≥ βevery concession is worth at least βcost algebras
No discardingnothing may be concededplain ABA

The boundary is non-strict: an extension costing exactly β survives. Sum ≤ β with β = 0 is not plain ABA — an attack of weight 0 is still discardable. Use ABA recovery for that. Under a cost algebra a bigger β is more restrictive, not less.

Semantics

SemanticsA set is accepted when
Conflict-freeit supports no attack on its own members
Stableconflict-free, and it attacks everything it leaves out
Admissibleconflict-free, and it answers every attack on itself
Completeadmissible, and it contains everything it defends
Preferredit is a subset-maximal admissible set

All five consume the weights. The last three carry their own budget (a structured lift of Dunne et al., AIJ 2011), so they take β directly and the budget-reading control does not apply.
